CAMPUS WORKFLOW ENGINES

The Three Intercepting Engines

All 1,000 students, 50 teachers, 5 HODs, and admin message ONE dedicated WhatsApp number. Engines never call each other directly; all cross-engine state routes through the database contract.

01 • INBOUND WEBHOOK

Herald Auto-Responder

The front door for every single message. Intercepts webhooks, checks active cases, and resolves 70% of messages directly from the database without hallucinations.

  • • Resolves attendance percentage & marks in 0.18s
  • • Auto-registers new students on their first message
  • • Answers pending assignments & deadline FAQs
  • • Routes complex cases into the Nexus queue
DIRECT DB READ • 0.18s LATENCY
02 • STATE MACHINE

Nexus Routing Engine

A case state machine where WhatsApp is the approval UI. Routes cases to faculty, collects natural language decisions, and records an append-only audit trail.

  • • Parses Hinglish approvals: "haan 2 din do", "ok"
  • • 24h timeout auto-escalates to the Admin Panel
  • • Conflict of interest detection for grievances
  • • Immutable audit trail in case_events (No DELETEs)
WHATSAPP IS THE APPROVAL INTERFACE
03 • RATE LIMITER

Dispatch Outbound

All outbound broadcasts route through Dispatch. Strictly rate-limits messages to guarantee the institution's WhatsApp number never gets banned.

  • • Rate-limited at 1 message / 0.8s via Baileys bridge
  • • Drafts professional notices from 1 sentence
  • • Admin approval gate: no bulk send without sign-off
  • • Emergency channel: 5 msg/sec with 30s undo window
ANTI-BAN RATE LIMITING: 1,000 RECIPIENTS ≈ 14M
[C1] ARCHITECTURAL INVARIANT

The Critical C1 Golden Rule: Check active_threads Before VANGUARD Always

Every incoming WhatsApp message — from students, faculty, or HODs — enters through the same Herald webhook. Before running LLM intent classification, Herald queries active_threads: "Is this sender's phone in an open Nexus case?" If YES: route directly to nexus.handle_reply() and VANGUARD is completely skipped. Without this check, faculty replies like *"yes give 2 days"* or *"haan theek hai"* get mistakenly classified as new student questions.
